# Portfolio Personal — Dylan Banegas 🚀

Sitio web personal de una sola página (**one-page**) moderno, rápido y 100% responsivo con animaciones fluidas, visor de código interactivo tipo IDE y **Simulador interactivo de CRM/ERP en vivo**.

---

## 🌟 Características Principales
- **Tecnologías**: HTML5 semántico, CSS3 moderno con acento azul (`#1A56B0`), Tailwind CSS CDN, JavaScript ES6+, Chart.js y SheetJS (XLSX).
- **Simulador Interactivo de Sistema CRM / ERP**:
  - 📊 **Dashboard & Analíticas**: Tarjetas KPI, gráficos en tiempo real de ingresos vs egresos y rendimiento de categorías.
  - 👥 **Módulo CRM de Clientes**: Búsqueda, estado comercial y registro de nuevos clientes.
  - 📦 **Inventario & Stock**: SKUs, precios de costo y venta, sumatoria y ajuste de stock en vivo.
  - 📅 **Calendario & Hitos**: Agenda de entregas de software e integraciones de proyectos.
  - 📑 **Finanzas & Exportación**: Tabla de movimientos con botón funcional de descarga de **Reporte en Excel (.xlsx)**.
- **Visor de Código / IDE Studio Interactivo**:
  - Explorador de archivos con snippets de código y arquitectura de **Rust (Tauri)**, **Node.js/MongoDB**, **Python (Odoo Sync)**, **n8n AI Agents** y **Web Accesible**.
  - Pestaña de Mockup y capturas visuales de cada desarrollo.
- **Skills Actualizadas**:
  - Supabase clasificada con nivel **Avanzada ⭐**.
  - Lenguajes (C#, JS, Python, SQL), Automatización (n8n, Zapier, AI Agents, APIs REST), ERP (Odoo, WooCommerce), Herramientas (Git, GitHub, Docker, Node.js, MongoDB, MySQL, Rust).
